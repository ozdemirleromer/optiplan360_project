# OptiPlan360 Documentation Naming Policy

## Canonical names
Use these exact filenames for the active documentation set:
- `OptiPlan360_Master_Spec_v4.md`
- `OptiPlan360_Extended_Modules_Annex_v1.md`
- `OptiPlan360_Phase1_Implementation_Spec_v3.md`
- `OptiPlan360_Phase2_Implementation_Spec_v2.md`
- `OptiPlan360_Phase2_UI_Spec_7Fields_v2.md`
- `OptiPlan360_Phase3_UIUX_Spec_v2.md`

## Naming rules
- Start every active spec with `OptiPlan360_`.
- Use English, descriptive, stable names.
- Keep one filename per domain.
- Use explicit version suffixes like `_v4`, `_v2`, `_v3`.
- Use `Master_Spec` only for the top-level binding document.
- Use `Annex` for extended but non-core modules.
- Use `Implementation_Spec` for implementation-facing phase documents.
- Use `UI_Spec` or `UIUX_Spec` for layout/interaction documents.

## Replacement mapping
- `OptiPlan360_Eksiksiz_phase4_Master_Spesifikasyon_v3.md` -> `OptiPlan360_Master_Spec_v4.md`
- `ebatlamaalani.md` -> `OptiPlan360_Extended_Modules_Annex_v1.md`
- `OptiPlan360_Master_phase1_Uygulama_Paketi_v2.md` -> `OptiPlan360_Phase1_Implementation_Spec_v3.md`
